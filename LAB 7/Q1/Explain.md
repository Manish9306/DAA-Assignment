**Question 1: Invert the Coin-Triangle**

**Algorithm**:
* Calculate the total number of coins and minimum moves using the formula[cite: 1].
* Represent the triangular lattice using row and column bounds[cite: 1].
* Identify coins located in the three corner regions that need to be relocated[cite: 1].
* Identify the corresponding vacant coordinates in the targeted inverted triangle[cite: 1].
* Output the coordinates for each coin slide and display the resulting inverted triangle[cite: 1].

**Time Complexity**: 
* O(1) for the formula; O(n^2) for move generation and grid display[cite: 1].
